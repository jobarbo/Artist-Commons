# Summary templates by session type

Copy the skeleton that fits, then fill from the transcript. Delete unused sections.

---

## Shared header (all types)

Class notes style — no speaker names, no attribution of who said what.

```markdown
# [Descriptive Title]

---

## Overview

What the session covers and why it matters (2–4 sentences).
```

Optional: `**Context:**` one line on topic or week in program (still no names).

---

## Workshop / artist presentation

```markdown
---

## [Project or session theme]

### [Subtheme — e.g. conceptual sources / pipeline step]

- …

### [Next subtheme]

- …

---

## Process and practice takeaways

- …

---

## Takeaways

- …
```

**Emphasis:** logical order of making (not strict chronology if transcript jumps), tools and materials, open questions, quotes from artists on process.

---

```markdown
## [Principle 2]

- …

---

- …

---

- …

```

**Emphasis:** numbered `##` sections like `113_portfolio`; concrete examples; "job application" analogies when speaker uses them; homework if assigned at end.
